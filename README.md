# QazaqRead

Қазақша мәтін оқу дағдысын онлайн талдау жүйесі — платформа для оценки техники чтения
вслух на казахском языке (1–4 классы). Ученик читает текст в микрофон, система распознаёт
речь, сравнивает каждое слово с текстом и считает скорость (слов/мин) и точность.

## Запуск

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
# модель распознавания казахской речи (60 МБ, один раз):
curl -L -o models/kz.zip https://alphacephei.com/vosk/models/vosk-model-small-kz-0.42.zip
#   и распаковать в models/  →  models/vosk-model-small-kz-0.42/
python manage.py seed_demo        # демо-данные (необязательно)
python manage.py createsuperuser  # доступ к /admin/ (необязательно)
python manage.py runserver
```

Откройте http://127.0.0.1:8000/. Голос ребёнка распознаётся **на сервере** (Vosk, офлайн,
работает в любом браузере): во время чтения правильные слова загораются зелёным, ошибки — жёлтым.

Демо-аккаунты (пароль у всех `qazaqread123`): учитель `mugalim`, родитель `serik`, ученик `aiaru`.

## Роли

| Роль | Что может |
|---|---|
| Оқушы (ученик) | библиотека текстов, чтение вслух с подсветкой слов, результаты и история |
| Ата-ана (родитель) | добавляет ребёнка по коду с QR-карты, видит динамику, печатает отчёт |
| Мұғалім (учитель) | классы, ученики, QR-карты, назначение текстов, проверка записей, экспорт в CSV |

## Сыныпта минуттық оқу (`/teacher/lessons/`)

Мұғалім кабинеті → «Сабақты бастау»: выбрать класс и текст. Ученики идут по списку
в казахском алфавитном порядке (по фамилии) и читают по одной минуте на компьютере учителя;
каждый результат сохраняется в аккаунт ученика. Отсутствующих можно пропустить («Сабақта жоқ»).
Затем учитель ставит оценки 2–5 (система предлагает оценку по норме и точности) и комментарий —
оценки видны ученику, родителю и учителю (`ReadingSession.mark`, модель `ClassReading`, `core/lesson.py`).

## Әкімші панелі (`/panel/`)

Вход: `admin` / `qazaqread123` (демо) или любой пользователь, созданный через
`python manage.py createsuperuser` — он автоматически получает роль «Әкімші».

- **Мәтіндер** — добавить, изменить, удалить текст (класс, сложность, тема, жанр,
  «текст дня»); число слов и время чтения считаются на лету.
- **Тест сұрақтары** — к каждому тексту вопросы с 2–4 вариантами и одним правильным,
  необязательное пояснение. После чтения ученик видит кнопку «Тест тапсыру».
- **Тест нәтижелері** — все попытки учеников с разбором ответов.
- **Пайдаланушылар** — поиск и смена роли (например, сделать человека учителем).

## Как работает оценка

1. `reading.js` записывает звук (MediaRecorder) и каждые 0,7 с отправляет кусок
   16 кГц PCM на `read/<pk>/live/`. Сервер держит распознаватель Vosk на каждую сессию
   (`live_feed` в `core/speech.py`) и возвращает услышанный текст; страница сравнивает его
   с текстом: правильные слова — зелёные, неверные и пропущенные — жёлтые.
2. По «Оқуды аяқтау» вся запись отправляется на сервер и распознаётся заново целиком
   (`models/vosk-model-small-kz-0.42`, ffmpeg из `imageio-ffmpeg`) — по ней считается итог.
   Живые распознаватели хранятся в памяти процесса: в продакшене нужен один процесс
   (например, gunicorn с одним воркером и потоками).
3. `core/analysis.py` выравнивает распознанные слова с текстом (difflib):
   дұрыс / тексеру қажет / өткізіп алынған. Слова после места, где ученик остановился,
   не считаются ошибкой.
4. Чтение длится **1 минуту** (`READING_SECONDS` в `core/models.py`): таймер идёт обратным
   отсчётом и запись останавливается сама. Если ученик дочитал текст раньше, скорость
   пересчитывается на минуту.
5. Скорость = правильно прочитанные слова в минуту; точность = правильные / прочитанные.
6. Учитель слушает запись и может исправить оценку любого слова кликом.

Если браузер не распознал речь, запись помечается «тексеру қажет», и её проверяет учитель.
Другую модель (например, большую `vosk-model-kz-0.42`) можно указать через `QAZAQREAD_VOSK_MODEL`.

Нормы скорости (слов/мин) заданы в одном месте — `GRADE_NORMS` в `core/models.py`:
1 класс 25–30, 2 класс 40–50, 3 класс 50–60, 4 класс 60–75.

## База данных: SQLite или PostgreSQL

По умолчанию используется файл `db.sqlite3`. Для PostgreSQL задайте переменную `DATABASE_URL`:

```powershell
$env:DATABASE_URL = "postgresql://postgres:ПАРОЛЬ@localhost:5432/qazaqread"
python manage.py migrate
python -X utf8 manage.py loaddata backup/qazaqread_data.json   # перенос данных из SQLite
```

Выгрузка данных из текущей базы (в т.ч. из SQLite, без `DATABASE_URL`):

```powershell
python -X utf8 manage.py dumpdata --natural-foreign --natural-primary -e contenttypes -e auth.permission -e sessions -e admin.logentry --indent 1 -o backup/qazaqread_data.json
```

## Render

- Build command: `./build.sh` (зависимости, модель Vosk, `collectstatic`, `migrate`).
- Start command: `gunicorn config.wsgi --workers 1 --threads 8 --timeout 120` — один воркер,
  потому что живое распознавание хранит состояние в памяти процесса.
- Переменные: `DATABASE_URL` (Internal Database URL от Render PostgreSQL), `DJANGO_SECRET_KEY`.
  `DEBUG` на Render выключен автоматически (по переменной `RENDER`).
- Аудиозаписи (`media/`) на диске Render стираются при каждом деплое — для постоянного
  хранения нужен Render Disk или внешнее хранилище.

## Важно перед запуском для реальных детей

- Голос ребёнка никуда не отправляется: распознавание полностью на вашем сервере (Vosk).
- Задайте переменные окружения `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, `DJANGO_ALLOWED_HOSTS`.
- Tailwind подключён через Play CDN — для продакшена соберите CSS через Tailwind CLI.
- Аудиозаписи лежат в `media/` и отдаются только через проверку доступа (`session_audio`).
